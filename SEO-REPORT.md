# SEO и техническая подготовка — 14 октября 2026

## Исходное состояние

Контрольный коммит до изменений: `55f6907`. Node.js 24, SQLite, клиентские улучшения HTML и Docker Compose + Caddy. Сайт использовал скопированный Tilda HTML; часть ссылок, canonical, OG и идентификатор Метрики относились к другому перевозчику. При загрузке JavaScript часть контента заменялась. Файл главной был около 1,38 МБ, содержал 29 скриптов в загруженном DOM. Публичные статьи уже были локальными, но не имели полного SEO-набора.

Другой домен ранее обозначен пользователем как конкурент. Редиректы на его сервере не настраивались. История кода сохранена Git; рабочая SQLite и пароли не включаются в Git.

## Выполнено

- Удалены переходы, metadata, верификация и счётчик чужого домена из используемого публичного HTML. Не заменяются настоящие внешние ссылки на мессенджеры и справочные источники.
- Сохранён существующий дизайн главной. Для серверного шаблона использована его текущая разметка, удалены неиспользуемые Tilda-скрипты, двойные элементы календаря и клиентские временные элементы.
- Главная, маршруты, статьи, контакты и FAQ возвращают полезный HTML без JavaScript. Цены, расписание, контакты и водители формируются из актуальной базы. Выбор мест остаётся интерактивным; без JS показан способ связи по телефону.
- Один H1 и уникальные title/description на 11 индексируемых страницах. Canonical, OG title/description/url/image/type/locale и Twitter Card указывают на poputi-vmeste.ru.
- JSON-LD: Organization с брендом и подтверждённым телефоном, Service для перевозок, Article для трёх статей, BreadcrumbList на внутренних страницах. Не добавлены рейтинги, юридический адрес, лицензии или неподтверждённые награды.
- Динамические robots.txt и sitemap.xml. Sitemap обновляется при включении/добавлении маршрута в админке. Только действующие канонические страницы; без выдуманных lastmod. Даты публикации статей соответствуют 14 октября 2026.
- Внутренние 301 для .html и завершающего /, 404 для отсутствующих страниц. Настройка Caddy перенаправляет www.poputi-vmeste.ru на основной домен; применяется при обновлении VPS.
- 19 используемых изображений имеют WebP-варианты 480/960/1440 px, srcset/sizes и размеры; ниже первого экрана — lazy loading. Основное изображение первого экрана предварительно загружается. Суммарный объём оригиналов этих изображений — 24,1 МБ; самых больших WebP-вариантов — 3,1 МБ. Это размер файлов, а не измеренные Core Web Vitals.
- Шрифты локальные, добавлен font-display:swap. Статика кэшируется 5 минут с перепроверкой, динамический HTML и данные — no-store. Caddy включает сжатие.
- Чужая аналитика отключена. Подготовлены METRICA_ID/GA4_ID в конфигурации, один скрипт аналитики и добровольный выбор посетителя перед загрузкой счётчиков. События: phone_click, messenger_click, booking_click, route_select, booking_success. Успех отправляется после ответа API; имена, телефоны и комментарии в события не передаются.
- SEO-тест проверяет серверный HTML, уникальность metadata/H1, JSON-LD, карту, внутренние ссылки, 301/404 и отсутствие чужого счётчика. Основные тесты бронирования сохраняются.

В браузере: главная проверена на 320/360/390/430/600/768/1024/1440 px без горизонтального переполнения; 10 внутренних страниц — на 320/390/768 px. Полный набор проверок кода, бронирования и SEO прошёл; npm audit --omit=dev — 0 уязвимостей на момент проверки. Рабочий HTTPS-домен до деплоя ответил HTTP 200 с доверенным сертификатом.

Проверка серверного HTML выполняется через HTTP без браузерного JavaScript. JSON-LD проверен программно по структуре. Публичные Schema.org Validator и Google Rich Results Test следует отдельно запустить после обновления VPS. Показ расширенных результатов не гарантируется.

## Развёртывание

```bash
cd ~/Po_puti
sudo bash deploy/update.sh
curl --fail https://poputi-vmeste.ru/api/health
curl -I https://poputi-vmeste.ru/robots.txt
curl -I https://poputi-vmeste.ru/sitemap.xml
```

Обновление делает копию данных перед загрузкой кода. Docker-сборку и TLS необходимо подтвердить на VPS: локально Docker отсутствует. DNS и действующий VPS автоматически не изменялись.

## Что требуется от владельца

1. Проверить реальные цены, расписание, вместимость, точки посадки, багаж, модель транспорта и контакты. На сайте отражены данные текущей админки, а не заново выдуманное расписание.
2. Заполнить данные оператора, сроки хранения, место базы и порядок удаления в политике. Проект политики не является окончательной юридической настройкой.
3. Предоставить собственные ID Метрики/GA4. После заполнения в `.env` применить `deploy/start.sh`. Обновить политику с учётом выбранных аналитических сервисов.
4. Для новых направлений подтвердить наличие рейса до добавления в админку.

## Вручную в поисковых системах

1. Добавить https://poputi-vmeste.ru в Яндекс Вебмастер и Google Search Console; подтвердить владение своим TXT или HTML-файлом.
2. Отправить https://poputi-vmeste.ru/sitemap.xml.
3. Проверить индексацию главной, маршрутов и статей; при необходимости запросить повторный обход.
4. Проверить JSON-LD публичными валидаторами после деплоя.
5. После подключения своих счётчиков настроить цели с указанными именами и проверить успешную заявку.
6. Собрать реальные поисковые запросы в Вордстате/Search Console, затем уточнять тексты без переспама.
7. Измерить скорость на production по PageSpeed Insights и реальным посещениям. Значения LCP/INP/CLS на 75-м процентиле нельзя подтвердить локальными тестами без достаточных полевых данных.

Попадание в топ и определённые позиции в Google/Яндексе не гарантируются.
