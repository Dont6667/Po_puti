Запуск сайта на Windows

Откройте START-WINDOWS.cmd. Нужен Node.js 24 или новее.
Если в .tools находится скачанный официальный Node.js, скрипт использует его автоматически.

Сайт: http://127.0.0.1:3001/
Админка: http://127.0.0.1:3001/admin
Первый пароль: data/admin-access.txt. Файл не доступен посетителям сайта.

В админке можно редактировать рейсы, время отправления, вместимость, цены,
фотографии, контакты и подтверждать/отменять заявки на поездки.
Данные сохраняются в SQLite. После изменения контактов обновите страницу сайта.

Запуск на VPS через Docker и резервное копирование описаны в README.md.
Команда запуска: docker compose up -d --build
